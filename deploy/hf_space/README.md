# Multiplex SIRS Viewer

Interactive 3D view of an SIRS epidemic on a contact network coupled to
information spread (independent cascade, linear threshold, or Friedkin–Johnsen
opinion dynamics) on a social network, with adaptive quarantine. Pick a
scenario in the side panel, then play or step the simulation and click nodes to
inspect them. The simulation is the project's Python code running in your
browser via Pyodide, so the first load takes a few seconds.

Source: https://github.com/Brodexe/Social_Contact_Multiplex
